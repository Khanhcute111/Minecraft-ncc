# Voxel Wilds

A browser-based voxel sandbox built with HTML, CSS, vanilla JavaScript modules, and Three.js from a CDN.

## Play
Open the GitHub Pages site after the first successful Actions deployment.

## Controls
- Desktop: WASD to move, mouse to look, left click to mine, right click to place, 1–6 to select a block, Space to jump.
- Mobile: landscape orientation, left joystick to move, drag the right side of the screen to look, ⛏️ to mine, 🧱 to place.

## Deploy
GitHub Actions publishes the repository root to GitHub Pages on every push to main. In Settings → Pages, select **GitHub Actions** as the build and deployment source if it is not selected automatically.

## Notes
The current hosted build is a compact single-file playable prototype. The downloadable project archive shared in the conversation contains the modular starter implementation and its supporting source files.
